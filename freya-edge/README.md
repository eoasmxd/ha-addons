# Freya (Edge)

[![Home Assistant Version](https://img.shields.io/badge/Home%20Assistant-2026.2.0%2B-blue.svg)](https://www.home-assistant.io/)

Edge preview channel of Freya AI Agent for testing latest bug fixes and experimental features.
Freya 智能体系统的先锋尝鲜通道，用于测试最新 Bug 修复与实验性特性。

---

### ⚠️ Warning: Unstable Build

**Freya (Edge)** is an **actively developing, experimental, and potentially unstable version** that directly tracks the latest code commits.

- 🧪 **For Testing Only**: May contain unresolved bugs, breaking changes, or unexpected behavior.
- 🛡️ **Production Use**: If you require stability and reliability, please install the official **Freya** app instead.
- 🔄 **Mutual Exclusion**: Freya and Freya (Edge) share persistent data (`/config/freya/`). **Please stop or uninstall the standard Freya app before starting this version.**
