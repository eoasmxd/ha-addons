# Changelog

## 0.6.3

- Upgrade Freya to `0.6.3`.
- Fix bug related to multilingual prompt resolution.
- Fix issue with excessively large historical data query results.

- 升级 Freya 至 `0.6.3`。
- 修复多语言提示词解析 BUG。
- 解决查询历史数据量过大的问题。

- Upgrade Freya to `0.6.1` with enhanced multi-language (i18n) support.
- Update dependencies and improve Home Assistant plugin integration.

- 升级 Freya 至 `0.6.1`，包含增强的多语言（i18n）支持与架构优化。
- 更新依赖项并优化 Home Assistant 插件集成。

- 新增内置 Home Assistant 专用智能交互工具箱，支持 Assist 实体状态感知与服务调用。

- Initial release of Freya Home Assistant Add-on.
- 适用于 Home Assistant 的 Freya 应用初始版本。
