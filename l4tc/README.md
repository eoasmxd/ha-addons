# L4Tunnel Client

[![Home Assistant Version](https://img.shields.io/badge/Home%20Assistant-2026.2.0%2B-blue.svg)](https://www.home-assistant.io/)

Layer 4 TCP tunnel client.
四层 TCP 内网穿透客户端。

---

### About

**L4Tunnel Client (`l4tc`)** is a lightweight Layer 4 reverse proxy tunnel client designed to expose your local Home Assistant instance or internal network services to public networks safely and efficiently.

### ✨ Key Features

- ⚡ **TCP Tunneling**: Pure Layer 4 TCP forwarding with low latency and low resource overhead.
- 🔄 **Dual Configuration Modes**: Supports both Home Assistant native UI form configuration and external `/config/l4tunnel/l4tc.ini` file configuration.

### 关于

**L4Tunnel Client (`l4tc`)** 是一款轻量的四层反向代理穿透客户端，旨在安全、高效地将本地 Home Assistant 实例或内网服务穿透映射至公网。

### ✨ 核心特性

- ⚡ **四层 TCP 转发**：纯四层 TCP 转发，低延迟与低资源开销。
- 🔄 **双模配置支持**：同时支持 Home Assistant 原生图形化配置表单与外部 `/config/l4tunnel/l4tc.ini` 原生配置文件。
