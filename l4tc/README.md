# L4Tunnel Client

[![Home Assistant Version](https://img.shields.io/badge/Home%20Assistant-2026.2.0%2B-blue.svg)](https://www.home-assistant.io/)

High-performance Layer 4 TCP/UDP tunnel client for Home Assistant.
高性能四层 TCP/UDP 内网穿透客户端，专为 Home Assistant 设计。

---

### About

**L4Tunnel Client (`l4tc`)** is a lightweight, high-performance Layer 4 reverse proxy tunnel client designed to expose your local Home Assistant instance or internal network services to public networks safely and efficiently.

### ✨ Key Features

- ⚡ **High Performance**: Pure Layer 4 TCP/UDP forwarding with low latency and minimal resource consumption.
- 🔄 **Dual Configuration Modes**: Supports both Home Assistant native UI form configuration and external `/config/l4tunnel/l4tc.ini` file configuration.

### 关于

**L4Tunnel Client (`l4tc`)** 是一款轻量、高性能的四层反向代理穿透客户端，旨在安全、高效地将本地 Home Assistant 实例或内网服务穿透映射至公网。

### ✨ 核心特性

- ⚡ **高性能传输**：纯四层 TCP/UDP 转发，极低延迟与极低资源开销。
- 🔄 **双模配置支持**：同时支持 Home Assistant 原生图形化配置表单与外部 `/config/l4tunnel/l4tc.ini` 原生配置文件。
