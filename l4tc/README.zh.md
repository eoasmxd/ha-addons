### 关于

**L4Tunnel Client (`l4tc`)** 是一款轻量的四层反向代理穿透客户端，旨在安全、高效地将本地 Home Assistant 实例或内网服务穿透映射至公网。

### ✨ 核心特性

- ⚡ **四层 TCP 转发**：纯四层 TCP 转发，兼具低延迟与低资源开销。
- 🛠️ **原生图形化配置**：直接通过 Home Assistant 应用选项完成配置，开箱即用。
